## 保留规则与完成状态的含义

- 保留函数、变量、宏、绑定、文件路径、API 与 PTX 指令；翻译普通自然语言注释，并在关键处解释动机。

- 保留原 Markdown 代码示例、命令与历史日志；有笔误或环境限制时在围栏外加译注，不伪造新运行结果。
- 保留英文原样副本、原有中文文章、署名与许可文本。中文文章中的原始英文引用也不在本轮改写范围内。
- 外部网站只翻译本仓库中的链接标题，不修改外部网页。代码样例里的标识符、公式、形状记号与被注释掉的程序仍按原用途保留。

因此，“完成”指当前固定基线下的文档入口与普通源码注释已逐模块覆盖；上游以后增加的文件需要重新盘点，不能沿用本次状态自动视为已翻译。

## 已记录但未在翻译中修复的原实现问题

| 范围 | 需要独立处理的事项 |
| --- | --- |
| 激活与其他向量化入口 | 宽预读早于保护、x2 无完整起点检查、网格向下取整漏尾部；输入关系与整数溢出未完整校验 |
| Cumsum / Sort | 存在空的 multi-CTA 扫描或自定义排序核；不能用入口存在或脚本结束证明已实现 |
| Embedding / 矩阵转置 | 文档列出的 x2 没有实际绑定；转置采集脚本引用仓库未提供的 `test_.py` |
| Normalization / RMSNorm | 无 epsilon 的原方差公式、消减误差、固定缓存容量和中间舍入 |
| GEMM / GEMV | 非完整网格重排组、宽访存/四行尾部、dtype 分派、TF32 数据准备格式需专项核实 |
| Flash Attention | 非方形 Q/KV 长度的因果语义与末 KV 分块有效长度掩码；TMA 填充不能代替 softmax 掩码 |
| Flash Decode | 单缓冲复用的同步关系需要专项 GPU 竞态检查；固定分片数也不是通用调优结论 |
| Sampling | BF16 按 FP16 位模式解包、top_k 错误消息与分派不一致、词表尾部及外部 logits 数据缺失 |
| RoPE / DSL | 维度整除与网格覆盖、dtype 与硬编码向量长度、DSL 生成的尾部掩码需实际核查 |
| 推理 / 硬件实验 | 固定两卡与固定形状、双流跨调用缓冲复用、单块实验索引以及缺失的结果断言 |
| 基准脚本 | 中位数仍被打印为 mean、平均/最大误差判据不同、原地修改输入或输出分配方式不统一 |

具体条件以各模块 README 和对应源码为准。后续算法修复、补全空实现、准备数据和 GPU 验证应独立提交，方便与本次翻译分开审核。
