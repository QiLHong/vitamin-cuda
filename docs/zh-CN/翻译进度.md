## 已做的静态验证

三个 Python 测试文件做了原版/注释版 AST 对比；三个 CUDA 源文件和一个公共头文件做了去除普通注释与空白的词法序列对比，并保留预处理指令检查。结果为代码 token/AST 未变化。上传后的 blob 哈希与已检查内容相符；具体哈希见 JSON 记录。

ReLU/Sigmoid 的本地原始副本还用 Git blob 哈希核对了 GitHub 读取的原始文件，确认静态比较对象确为对应仓库版本。对这四个新增注释文件的差异检查没有输出新增空白错误诊断。

这些是静态一致性检查，不是完整的编译器语义证明，也不能保证跨工具链生成逐字节相同的二进制。中文注释会改变源码行号及可能的调试信息，因此不声称任何构建产物必然逐字节一致。

## 已记录但未修复的原实现限制

部分宽访存出现在边界判断之前；ReLU x2 完全没有核内边界判断；Sigmoid x2 的单元素分支未检查起点；部分打包版本虽然有核内保护，网格公式仍可能漏掉非整组尾部。包装也未完整检查形状、dtype、设备、对齐与重叠关系。空输入和超大输入不在当前入门约定内。测试输出写 mean，实际统计 median。

这些分别在对应源码与模块说明中标注，没有混入算法修复。数学边界、NaN/Inf 和具体架构行为仍需要真实测试。

## 后续中文化的一致规则

保留函数、变量、宏、绑定、文件路径与运行时字符串；翻译自然语言并解释动机；逐项核对数学公式、线程映射、字节布局、边界、同步与架构前提；只改普通注释，不在续行宏中插入会吞掉反斜杠的行注释。新增说明区分原实现事实、纸面推导、历史性能记录和未运行示例。

完成更多模块时更新本表。修复算法应独立提交，与翻译分离，便于审核。
